# Wallpaper

## Cycle Wallpaper
Cycles through images in `wallpaper/` on the main display.
- `lalt - j` — next
- `lalt - k` — prev

## Add a Wallpaper
Downloads an image from a URL, normalizes it to PNG in `wallpaper/`, then commits and pushes.
```sh
pnpm wallpaper https://example.com/image.jpg
```
